# Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/OmkarArdekar12/auratime-watches.git
```

## 2. Navigate to the Project

```bash
cd auratime-watches
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Run the Development Server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
